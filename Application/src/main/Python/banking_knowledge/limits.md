# Limits — Transactional & Account Limits

## Types of Limits
- **Per-transaction limit**
- **Daily limit**
- **Monthly limit**
- **Card ATM withdrawal limit**
- **UPI merchant single TX / daily limits**

## Where limits live
- Product / account tier configuration (savings gold/premium)
- Regulatory caps (e.g., RBI circulars)
- Per-customer customized limits (risk profiles)

## How to change limits
- Identify user role & entitlement
- Require re-authentication (OTP / 2FA)
- Log audit trail for limit changes
- Trigger notification to customer (SMS / Email)

## Common Failure Reasons
- Exceeded daily limit
- Transaction exceeds per-merchant limit
- Temporary fraud hold reducing available limit
